What it does

One click. A clear verdict.

Click the toolbar icon on any site and IsItDown tells you exactly what's wrong — or confirms nothing is.

Up / Down / Slow verdict

A single, unambiguous status backed by HTTP code, response time, and DNS resolution — not a guess.

Passive slow-page badge

Watches every page load in the background. A yellow ! or red ? badge appears with zero clicks.

Recovery watcher

When a site is down, opt to be notified the moment it comes back — polled quietly every 30 seconds.

Monitoring dashboard

Track up to 10 sites at once. Background checks every 5 minutes, with a global badge if any go down.

Fix suggestions

Context-aware troubleshooting for DNS failures, timeouts, and HTTP 401/403 — copyable in one click.

History & reports

The last 50 checks, exportable to CSV, plus a one-click diagnostic report for support tickets.

How it does it

A dual-check engine, running entirely in your browser

No server to trust. The extension's background service worker does the diagnosis itself.

1

You click "Check now"

The popup reads the active tab's domain and sends it to the background service worker via chrome.runtime.sendMessage.

2

Two checks run in parallel

HTTP probe — a direct HEAD, falling back to GET, against the domain with an 8s timeout. DNS check — a lookup against Google's public resolver (dns.google/resolve) to confirm the domain resolves at all.

3

The results are cross-referenced

This is what separates IsItDown from a plain ping: if HTTP fails but DNS succeeds, the server itself is down. If both fail, it's likely your network or the domain is gone entirely.

4

A verdict is built and returned

The popup renders the verdict card, the response-time / HTTP / DNS stats, and — if something's wrong — targeted fix suggestions. The result is saved to local history.

ConditionVerdict
HTTP responds, status ≥ 500Server Error
HTTP responds, took >3000msDegraded Performance
HTTP responds normallyAll Good
HTTP fails, DNS resolvesAppears Down
HTTP fails, DNS also failsSite Unreachable
Why it exists

The "is it just me?" moment, solved

A site fails to load and you're left guessing: broken DNS? A dead server? A flaky VPN? Third-party outage-tracker sites are slow, ad-heavy, and can't see your local network conditions at all.

Your own vantage point matters

A third-party status page checks a site from its own servers — not from your network, behind your VPN, with your DNS. IsItDown probes from exactly where you are, so the diagnosis is actually about your situation.

Speed over searching

No tab-switching to a downtime checker, no CAPTCHA, no ads. One click in the toolbar, an answer in seconds — while you're already looking at the broken page.

Diagnosis, not just status

"Down" isn't enough. Knowing why — DNS failure vs. server error vs. timeout — points straight at the right fix instead of a shrug.

Built to stay out of the way

The passive badge and monitor list work silently in the background, so the common case (everything's fine) costs you nothing.

Privacy & permissions

No backend. No accounts. No tracking.

Everything runs on your machine

IsItDown never collects, transmits, or sells any personal data. The only external service it ever contacts is dns.google, and only to verify DNS resolution for the site you're actively checking. History, monitor lists, and settings live in chrome.storage.local — never leaving your browser. Permissions (storage, alarms, notifications, webNavigation, activeTab, and host access) exist solely to run checks, schedule background polling, and show recovery notifications.

Get started

Install in under a minute

No Chrome Web Store listing yet — load it straight from source.

1
Clone the repo — git clone https://github.com/Jaswanth-dev-69/isitdown-extension.git
2
Open chrome://extensions and enable Developer mode
3
Click Load unpacked and select the cloned isitdown-extension folder
4
Pin the icon from the toolbar puzzle menu — you're ready to check any site
